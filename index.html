The probe isn't in the list

Three reasons, all normal, none of them a fault:

  1. Bluetooth is switched off on the probe. The setting lives in the probe's own web app and it persists. Units ship with it enabled.
  2. The provisioning access point is open. WiFi and Bluetooth share one 2.4 GHz radio, so advertising stops while the AP is up — for up to ten minutes, or until the operator closes it.
  3. Something else is already connected. The probe accepts one connection at a time and stops advertising while it holds it, so it goes absent from the list rather than appearing as busy.

Close any phone app that might be holding the connection, then try again.

Using an iPhone or iPad

Safari has no Web Bluetooth, and Chrome and Edge on iOS are Safari underneath, so none of them can reach the probe — they will not even offer to try. Bluefy, from the App Store, is a browser that adds Web Bluetooth on iOS. Open this same address in it and everything works as it does on Android.

Because Bluefy is not Safari, iOS will not let you add this page to the home screen from it. Bookmark it inside Bluefy instead, and check before going out that it still opens with the phone off the network.

Read-only. Nothing in this app can change the probe — configuration, WiFi credentials and calibration are reachable only from the probe's own web app.
